下载 SimTab 扩展

已上线 Microsoft Edge 加载项商店，也可从 GitHub 手动安装。

从 Edge 商店安装

其他 Chromium 浏览器：手动安装

前往 GitHub Releases 下载 SimTab-1.0.5-edge.zip，然后按以下步骤安装。Edge 用户可直接使用上方商店入口。

  1. 下载并解压

    解压 ZIP 文件，保留解压后的文件夹。安装完成后也请保留，浏览器仍需从中读取扩展文件。

  2. 打开扩展管理

    复制下方对应地址，粘贴到浏览器地址栏并打开，再开启“开发者模式”或“开发人员模式”。

    Chrome
    chrome://extensions
    Edge
    edge://extensions

    其他 Chromium 浏览器可从菜单进入扩展管理页面。

  3. 加载扩展文件夹

    点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。

  4. 打开新标签页

    新标签页将显示 SimTab。如浏览器询问是否保留此更改，选择保留即可。

开始使用

把收藏带过来

在扩展的网站库中打开“我的收藏夹”，授权后即可选择添加书签。

网页版可在“设置 → 数据”中导入浏览器导出的 HTML 书签文件。

在设备间同步

网页与扩展登录同一账户，并选择使用云端内容，即可访问同一份收藏。

未登录时使用本地内容，退出登录后恢复本地内容。将本地内容复制到云端会替换账户内容，并保留本地副本。

备份与恢复

在“设置 → 数据”中导出 JSON 备份。恢复备份会覆盖当前内容，操作前请先导出留存。
