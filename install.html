安装浏览器扩展

SimTab 扩展将常用网站放在每一个新标签页，并支持经你授权后读取 Edge 收藏夹。

从源码手动安装

下载 GitHub 源码 ZIP

  1. 解压下载的 ZIP，保留文件夹。
  2. 在 Edge 地址栏输入 edge://extensions，开启“开发人员模式”。
  3. 选择“加载解压缩的扩展”，选中包含 manifest.json 的文件夹。
  4. 打开新标签页；如 Edge 询问是否保留新标签页更改，按你的偏好确认。
  5. 在“热门网站 → 我的收藏夹”中点击允许读取收藏夹。

网页版与扩展版

安装扩展不会让普通网页直接获得读取收藏夹的权限。请在扩展的新标签页中使用直接读取功能。网页版可在“设置 → 账户与数据”选择 Edge 导出的书签 HTML 文件。

网页和扩展登录同一账户即可通过云端同步。未登录时直接使用此浏览器本地内容，退出登录会恢复本地内容；本地内容可在“账户与数据”中主动复制到云端，并保留本地副本；也可以导出 JSON，再在目标账户导入。JSON 恢复会覆盖账户已有数据。
