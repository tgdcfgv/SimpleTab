SIMTAB

隐私政策

适用于 SimTab 2.4.0 的 Microsoft Edge 扩展及网页版。更新日期：2026 年 10 月 21 日。

账户与云端数据

SimTab 使用 Supabase 提供邮箱注册、登录及云端数据库，项目位于新加坡。邮箱、密码由 Supabase Auth 处理；应用不会保存明文密码。登录后，空间、分组、网站标题与地址、排序、主题、自定义图标地址及旧版远程壁纸地址会上传并保存在当前账户的云端记录中。数据库按账户隔离访问。Supabase 会处理服务所需的网络信息和日志。

无需登录即可使用。未登录的内容保存在当前浏览器：扩展使用 chrome.storage.local，网页使用 localStorage。主动登录后可选择使用云端内容覆盖当前页面，或将当前页面保存到云端。确认选择前不读取或写入账户配置；本地副本始终保留，退出后恢复本地内容；登录凭证保存在 localStorage 以维持登录。云端内容不写入浏览器本地内容，未同步更改仅保留在当前页面。两份内容不会自动上传、合并或覆盖。主动将本地内容复制到云端时会替换当前账户内容，并保留本地副本。

自定义壁纸

上传的壁纸独立保存在当前浏览器的 IndexedDB，不上传云端，也不包含在 JSON 导出中。旧版备份中的内嵌壁纸会先保存到本机，再从配置中移除；其他设备需自行选择图片。清除浏览器数据或卸载扩展可能删除本机壁纸。

快捷收藏

仅在你点击扩展工具栏图标、使用快捷键或选择页面右键菜单后，扩展才读取当前页面标题和网址。草稿暂存于浏览器会话存储，确认空间和分组后按当前本地或云端状态保存；取消不会添加网站。草稿在 30 分钟后失效，后续收藏时清理；保存或取消时清理，失败时可保留以便重试，关闭浏览器会清除。扩展不读取页面正文、浏览历史或其他未主动选择的标签页。

收藏夹与导入文件

只有在你打开扩展中的“我的收藏夹”并同意书签权限后，SimTab 才会通过 Edge 的书签接口读取书签标题、网址和文件夹路径，用于展示和选择添加。SimTab 不创建、修改或删除浏览器原有书签。你可以在扩展管理中撤销权限。网页版不能直接读取收藏夹。你主动选择的 HTML 书签文件和 JSON 备份在本地读取和解析，导入后的内容在未登录时保存在浏览器，登录后保存到当前账户云端。导出文件可能包含你的私人网址，请自行保管。

联网请求与第三方

  • 扩展的默认图标使用浏览器提供的 favicon 接口；浏览器可能按自身规则获取或缓存图标。网页版默认通过 a.favicon.im 获取网站图标，该服务可能收到所请求网站的主机名、网络地址和常规请求信息。
  • 预设或你自定义的远程图标会向图片提供方发出请求。旧备份若含有第三方图标地址，导入后也会请求这些地址。第三方可能按其政策记录访问日志。
  • 搜索时，你输入的搜索词会传给你选择的搜索引擎。打开网站会直接访问该网站，其数据处理适用对方的隐私政策。
  • 网页版由 Cloudflare 托管。访问页面时 Cloudflare 会处理提供网络服务所需的 IP 地址、请求信息和安全日志。GitHub 提供源码、下载及问题反馈服务。

2.1.0 不再抓取目标网页正文，不使用 AllOrigins 代理，也不会因获取默认图标而把完整网址转发给此类网页代理。扩展不加载或执行远程脚本。

权限用途

  • storage：保存和读取未登录时的本地网站及设置，也可读取本地内容供你主动复制到云端；会话存储暂存你主动发起的收藏草稿。
  • Supabase 项目访问权限：仅访问本应用的 Supabase 域名，用于登录及云端数据读写。
  • activeTab：在你主动点击工具栏图标或使用快捷键后，临时读取当前页面标题和网址以便收藏。
  • contextMenus：提供“保存当前页面到 SimTab”页面右键菜单。
  • favicon：在扩展界面显示网站图标。
  • bookmarks（可选）：在你主动授权后读取收藏夹供选择导入。

删除与控制

你可删除应用中的网站或分组、移除自定义壁纸，未登录时修改保存在浏览器，登录后修改同步到云端。网页、扩展和其他设备登录同一账户后可读取同一份数据。退出登录清除本机登录状态，并恢复本地内容。清除浏览器数据或卸载扩展可能删除本地内容，但不会删除云端记录。需删除账户及全部云端记录时，请通过下方项目反馈渠道联系维护者，勿公开密码或私人网址。已下载到磁盘的备份需单独删除。
