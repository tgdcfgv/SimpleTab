SIMTAB

隐私政策

适用于 SimTab 2.1.0 的 Microsoft Edge 扩展及网页版。更新日期：2026 年 10 月 21 日。

本地保存的数据

空间、分组、网站标题与地址、排序、主题、自定义图标地址和壁纸保存在你使用的浏览器中。扩展使用 chrome.storage.local，网页版使用当前网站的 localStorage。没有账号系统、广告分析或开发者提供的云同步，也不会将完整收藏夹或配置上传到开发者服务器。

收藏夹与导入文件

只有在你打开扩展中的“我的收藏夹”并同意书签权限后，SimTab 才会通过 Edge 的书签接口读取书签标题、网址和文件夹路径，用于展示和选择添加。SimTab 不创建、修改或删除浏览器原有书签。你可以在扩展管理中撤销权限。网页版不能直接读取收藏夹。你主动选择的 HTML 书签文件和 JSON 备份在本地读取和解析，不上传。导出文件可能包含你的私人网址，请自行保管。

联网请求与第三方

  • 扩展的默认图标使用浏览器提供的 favicon 接口；浏览器可能按自身规则获取或缓存图标。网页版默认通过 icons.duckduckgo.com 获取网站图标，该服务会收到所请求网站的主机名、网络地址和常规请求信息。
  • 预设或你自定义的远程图标会向图片提供方发出请求。旧备份若含有第三方图标地址，导入后也会请求这些地址。第三方可能按其政策记录访问日志。
  • 搜索时，你输入的搜索词会传给你选择的搜索引擎。打开网站会直接访问该网站，其数据处理适用对方的隐私政策。
  • 网页版由 Cloudflare 托管。访问页面时 Cloudflare 会处理提供网络服务所需的 IP 地址、请求信息和安全日志。GitHub 提供源码、下载及问题反馈服务。

2.1.0 不再抓取目标网页正文，不使用 AllOrigins 代理，也不会因获取默认图标而把完整网址转发给此类网页代理。扩展不加载或执行远程脚本。

权限用途

  • storage：保存你的配置和网站列表。
  • favicon：在扩展界面显示网站图标。
  • bookmarks（可选）：在你主动授权后读取收藏夹供选择导入。

删除与控制

你可删除应用中的网站或分组，移除自定义壁纸，并通过浏览器清除当前网站数据或卸载扩展来清除相应本地存储。网页和扩展、不同域名及不同设备的存储互相独立。卸载前如需保留数据，请导出 JSON 备份。已下载到磁盘的备份需单独删除。
