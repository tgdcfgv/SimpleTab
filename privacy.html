SimTab 隐私政策

适用于 SimTab 1.0.0 的 Microsoft Edge 扩展及网页版。我们始终坚守「本地优先、极简授权、数据完全归用户所有」的安全承诺，保障你的数字资产与隐私空间。

本地优先存储

无需注册或登录即可完整使用。未登录时数据安全存放于浏览器本地，不向任何云端上传。

密码强加密

由专业云端基础设施 Supabase Auth 加密处理邮箱和密码，应用绝不存储任何明文密码。

零侵入与追踪

不抓取网页正文，不搜集浏览历史，无任何第三方分析追踪 SDK，代码全部开源。

权限按需授权

Edge 收藏夹只在主动点击时按需请求读取，不修改原有书签，且随时可在浏览器管理中关闭。

1. 账户与云端数据

Supabase 认证、数据存储范围与本地隔离保障

云端基础设施与密码安全

SimTab 使用 Supabase 提供邮箱注册、登录及云端数据库，数据中心位于新加坡。邮箱、密码由 Supabase Auth 负责处理；应用自身绝不接触或保存你的明文密码。在登录状态下，你的空间、分组、网站标题与地址、排序、主题、自定义图标地址及旧版远程壁纸地址会上传并保存在当前账户的云端记录中。数据库按账户采用行级安全策略（Row-Level Security）实现严格的隔离访问。Supabase 会处理服务运行所需的网络信息和基础运行日志。

未登录使用与双份数据隔离机制

SimTab 无需登录即可使用。未登录时的所有内容均直接保存在当前浏览器：扩展版使用 chrome.storage.local，网页版使用 localStorage。

主动登录后，你可以根据需要选择使用云端内容覆盖当前页面，或将当前页面保存到云端。在确认选择前，应用不会读取或写入账户配置；本地副本始终完整保留，一旦退出登录将自动恢复你的本地内容。登录凭证保存在 localStorage 中以维持会话。

云端内容绝不会自动静默写入浏览器本地存储，未同步更改仅临时保留在当前活跃页面。本地与云端两份内容绝不会自动上传、合并或覆盖。主动将本地内容复制到云端时会替换当前账户内容，并完整保留本地副本。

2. 自定义壁纸

本地 IndexedDB 存储与跨端处理说明

你上传的自定义壁纸图片均独立保存在当前浏览器的本地数据库（IndexedDB）中，绝不上传至任何云端服务器，也不包含在导出的 JSON 备份文件中。这样既能保证高分辨率壁纸的瞬时秒开加载，又能最大限度保护个人图片隐私并节约网络带宽。

旧版备份中若包含内嵌壁纸，在导入时会先完整保存到本机，随后从配置记录中移除；在其他设备上使用时需自行重新选择图片。请注意：若在浏览器中执行“清除所有网站数据”或卸载扩展，可能会删除本机保存的壁纸文件。

3. 快捷收藏功能

触发时机、会话暂存草稿与生命周期管理

仅在你主动操作时触发：只有在你主动点击扩展工具栏图标、按下全局快捷键（默认 Alt+Shift+S）或在网页上右键点击“保存当前页面到 SimTab”时，扩展才会临时读取当前标签页的页面标题和网址。

读取到的草稿会暂存在浏览器会话存储（Session Storage）中，待你在弹窗中确认指定空间和分组后，再按当前本地或云端状态正式保存；如果点击取消，则不会添加任何网站记录。草稿在 30 分钟后自动失效，并在后续发起收藏时自动清理；保存或取消时也会立即清理；如果保存失败，则允许临时保留以便你重试；关闭浏览器标签页或退出浏览器会自动彻底清除。

明确声明：扩展绝不读取任何页面正文内容、绝不窥探浏览历史、绝不扫描其他未被主动选择的后台标签页。

4. 收藏夹与导入文件

Edge 原生书签权限范围与备份导入隐私规范

Edge 原生书签只读权限

只有在你主动打开扩展中的“我的收藏夹”并明确同意授权书签权限后，SimTab 才会通过 Edge 的书签接口读取书签标题、网址和文件夹目录路径，仅用于在界面中展示并供你挑选需要添加到新标签页的网站。SimTab 绝不创建、修改、覆盖或删除浏览器原有的任何书签。你可以在 Edge 扩展管理页面中随时撤销此权限。纯网页版无法直接调用浏览器书签接口。

文件导入与备份处理

你主动选择上传的 HTML 书签文件和 JSON 备份文件完全在浏览器本地进行读取和解析。导入完成后的内容，在未登录状态下保存在浏览器本地，登录后同步到当前账户的云端。导出的备份文件可能包含你的私人网站收藏，请妥善保管并避免公开上传。

5. 联网请求与第三方服务明细

所有可能产生外部网络交互的场景与数据流向清单

网站图标获取 (Favicon)
扩展版默认使用 Chromium 浏览器内置的 chrome-extension://.../_favicon/ 原生接口，浏览器按自身安全规则获取或缓存图标。网页版受浏览器安全沙箱限制，默认通过 a.favicon.im 获取图标，该服务仅会收到所请求网站的主机名（域名）、网络地址和常规 HTTP 请求信息。
搜索联想词与搜索引擎
在搜索框中键入内容时，应用会向 Bing 搜索建议接口获取实时联想词；回车提交搜索时，你输入的搜索关键词会直接传递给你选定的搜索引擎（如 Google 或 Bing）。点击打开网站卡片将直接访问目标网站，其数据处理适用该网站自身的隐私政策。
云端托管与分发服务
网页版由 Cloudflare 全球网络进行静态托管与加速，访问页面时 Cloudflare 会处理提供网络服务所需的 IP 地址、请求信息和安全防御日志。GitHub 提供开源代码托管、扩展压缩包下载及 Issues 问题反馈服务。
自 1.0.0 版本起，SimTab 不再抓取任何目标网页正文，不再使用 AllOrigins 等第三方 CORS 代理，绝不会因获取默认图标而把完整网址转发给此类网页代理服务。扩展坚决不加载或执行任何远程脚本代码。

6. 扩展权限用途清单

每一项浏览器权限均有明确的单一用途，绝不过度申请

storage 核心权限

保存和读取未登录时的本地网站分组及设置，并在你主动请求时读取本地内容复制到云端；在会话存储（Session）中临时暂存你主动发起的快捷收藏草稿。

Supabase 项目域名 网络权限

仅限访问本应用的专属 Supabase API 域名，用于用户自愿登录账号认证以及云端数据记录的安全读写，绝不连通其他未知云端域。

activeTab 快捷操作

仅在你主动点击工具栏图标或按下快捷键（Alt+Shift+S）后，临时读取当前前台标签页的标题与网址以完成快捷收藏。

contextMenus 快捷菜单

在网页右键菜单中提供“保存当前页面到 SimTab”快捷入口，便于你随时将心仪网站一键存入标签页。

favicon 界面展示

通过浏览器原生 Favicon 接口在扩展的新标签页和网站挑选界面中展示对应站点的官方图标。

bookmarks 可选按需授权

在你主动打开“我的收藏夹”并确认授权后调用 Edge 书签接口，以只读方式展示你的书签供你挑选导入，可随时在浏览器扩展管理中撤销。

7. 删除与数据控制权利

完全自主掌控你的数据生命周期

你拥有对所有保存数据的完全控制权：随时可以修改或删除任何网站、分组或空间，也可以直接移除自定义壁纸。未登录时的所有修改立即保存在本地浏览器；登录状态下的修改实时同步至云端。

网页端、扩展端及其他设备登录同一账户后可访问同一套数据。退出登录将立即清除本机登录凭据，并完整恢复此设备的原有本地内容。请注意：在浏览器中清除缓存或直接卸载扩展可能会删除本地内容，但绝不会删除已同步在云端的账户记录。

如需彻底注销账户并永久删除全部云端记录，请通过下方项目反馈渠道联系维护者（请勿在公开问题中透露密码或私人网址）。已主动导出或下载到磁盘的 JSON 备份文件需由你自行手动删除。

透明的反馈通道与版本迭代承诺
